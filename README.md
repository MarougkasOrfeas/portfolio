# My Portfolio

Personal portfolio website.
It is a plain HTML, CSS and JavaScript site designed for deployment on GitHub Pages.

## Features

* Responsive Design.

* Interactive Career Timeline.

* Project Showcase.

* Multilingual Support - English and Greek translations.

* Animations and Interactions.

* Accessibility.

## Getting Started

The portfolio is a static website and you can visit it here https://marougkasorfeas.github.io/portfolio/.

#### To Run Locally: <br>
Clone the Repository

``` 
git clone https://github.com/MarougkasOrfeas/portofolio.git 
cd portofolio 
```

<br>You need to start a local server. You can use the Live Server extension in Visual Studio Code or start one using Python: 
```
python -m http.server 8000
```
And open: http://localhost:8000

<i>Note: JavaScript ES modules require an HTTP server, the website should be served locally rather than opened directly using the file:// protocol.
</i>

## Accessibility

Accessibility has been considered throughout the development process.

The website includes semantic HTML elements, accessible navigation, keyboard-operable controls, descriptive labels, and screen reader announcements.

Animations respect the user's prefers-reduced-motion preference, and a dedicated control allows visitors to pause animations.

Additional considerations include visible keyboard focus indicators, responsive text and layouts, and support for high-contrast display preferences.

The implementation is designed with WCAG accessibility guidelines in mind.
